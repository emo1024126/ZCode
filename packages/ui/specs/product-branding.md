# Product-facing brand copy

## Behavior

- User-visible application, Web, shared-session, and CLI/TUI copy uses `Codex` as the product name.
- User-visible variants such as `ZCode Agent`, `ZCode MCP`, and `ZCode Guide` use the corresponding `Codex` wording.
- Internal identifiers, protocol names, environment variables, CSS hooks, storage keys, compatibility paths, and persisted data directories remain unchanged.

## Acceptance

- Locale values do not render `ZCode` in the desktop or Web UI.
- Visible labels, titles, alt text, aria labels, CLI/TUI startup copy, and official plugin descriptions use `Codex`.
- Existing `ZCode` identifiers and compatibility paths remain available to the runtime.
